# decisoes/

Histórico de decisões, um arquivo por decisão. Nome no padrão
`[AAAA-MM-DD]-[assunto-curto].md`, usando o `TEMPLATE.md` desta pasta.

Aqui fica o histórico da discussão: o que foi considerado, o que foi decidido
e por quê. O estado atual de cada frente fica nos arquivos de `operacao/` e
`trafego/`, não aqui.

Achado relevante que ainda não virou decisão também entra, com o prefixo
`achado` no nome do arquivo, para não sumir até alguém decidir o que fazer.
