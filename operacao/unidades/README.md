# operacao/unidades/

Estado de configuração de cada unidade, um arquivo por loja, nome curto em
minúsculas (`[unidade].md`). Use o `TEMPLATE.md` desta pasta.

O que mora aqui é o estado da unidade: ID, CNPJ, endereço, horário, o que já
está configurado no sistema e o que falta. O que é regra da rede fica no
`../CLAUDE.md`.
