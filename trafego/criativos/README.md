# criativos/

Peça e print de cada criativo com o resultado que ele entregou (CTR, custo por
resultado, gasto).

Nomeie o arquivo no mesmo padrão da campanha:
`GEB_[Unidade]_[Objetivo]_[Oferta]_[MMDD]`.

Cada criativo com resultado ganha um `.md` ao lado, com o ângulo testado, a
hipótese e o que o número disse.
